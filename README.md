# ACM CONNECT

**Connecting Industry Challenges with Academic Innovation**

This repository is intended to hold the source for the ACM CONNECT platform, an industry-academic collaboration initiative for the American College of the Middle East (ACM), Kuwait.

## Platform journey

1. Companies submit real operational, technical, and business challenges.
2. ACM reviews challenges and aligns suitable work with academic programs and faculty supervision.
3. Students and faculty form interdisciplinary teams.
4. Teams work through project tasks, milestones, and industry feedback.
5. ACM evaluates outcomes and reports measurable impact.

## Design direction

Follow the official ACM institutional identity: a clean white/light interface, ACM blue as the primary color, restrained red accents, and the official ACM logo supplied by the institution. Do not recreate or distort the logo.

## Migration notes

- Existing application source remains in the Lovable project until a secure, complete migration is completed.
- Supabase is enabled in the current Lovable project. Preserve the existing schema and migrations; never commit credentials or .env secrets.
- Demo/example records must be clearly identified as illustrative rather than actual ACM performance data.
- Treat faculty as the internal evaluators of outcomes; industry partners provide challenge context and feedback.
